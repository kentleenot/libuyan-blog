# 欢迎来到我的博客

> 桃李不言，下自成蹊。

这是我的第一篇文章。这个博客用来沉淀我的**学习笔记**和**技术文章**，内容会围绕我持续在做的事情展开：

## 我会写什么

- **量化交易**：策略思路、回测分析、交易系统的工程实践
- **技术学习**：读源码的笔记、新框架的探索、踩坑记录
- **思考沉淀**：第一性原理的分析方法、投资研究的心得

## 为什么开这个博客

学习最大的敌人是遗忘。写下来，既是整理，也是未来的自己可以随时查阅的笔记。如果这些内容恰好对路过的你有帮助，那是额外的收获。

## 关于更新

文章不定期更新，质量优先于数量。欢迎通过 GitHub 交流。
